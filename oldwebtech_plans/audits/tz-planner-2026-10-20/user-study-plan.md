# Pending participant study

Recruit five people who arrange meetings across time zones for a first qualitative review. Include frequent and occasional organizers. Include a keyboard user. Include a phone user. Recruitment requires separate authorization.

Use a disposable copy of the planner. Start each participant with the same date and defaults. Do not explain controls before the tasks.

1. Arrange a 45-minute meeting for New York, London, and Kolkata. Ask the participant to find a time within each office's stated hours. Success requires the full meeting to fit each interval or a correct no-overlap conclusion.
2. Add Coordinated Universal Time by typing UTC. Success requires the correct zone and matching instant.
3. Change the meeting across midnight. Ask the participant to state each local date. Success requires correct dates.
4. On a phone, return to the selected time after scrolling the timeline. Success requires finding the selected column without help.
5. Reload the page. Ask the participant to recover the plan. Success requires checking the retained date and zones.

Record unassisted completion, assisted completion, failure, errors, recovery, and comments. Stop on participant request or sustained inability to proceed. Give help only after recording the barrier. If timing is used, start after the scenario is read and stop at the participant's final answer. Exclude moderator interruptions. Keep timing separate from agent tool delays.

Use the unchanged Single Ease Question after each task. If a session questionnaire is needed, use the unchanged System Usability Scale with its standard scoring. Do not create scores before participants complete the study. Compare the proposed changes with the current page using equivalent scenarios. This small study provides qualitative evidence, not a population estimate.
