## Behavior

For a supported visual, Analyze explains an increase or decrease relative to the immediately previous data point.

## Defaults or baseline

The selected point defines the comparison.

## Gotchas

Analyze is unavailable for the first point because there is no previous point. Its documented support restrictions still apply.

## Verify

Read the Microsoft sections below. No live Power BI report was tested.

## Applies to

PL-300 skills effective April 20, 2026: Visualize and analyze the data > Identify patterns and trends > Use the Analyze feature in Power BI. No question assigned.
