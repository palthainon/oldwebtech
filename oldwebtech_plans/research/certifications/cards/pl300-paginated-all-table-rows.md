## Behavior

Choose a paginated report when a printed table must include every row across as many pages as needed.

## Defaults or baseline

A paginated report controls page layout for printing.

## Gotchas

Printing a regular report page with a scrolling table includes the visible rows, not every row behind its scrollbar.
