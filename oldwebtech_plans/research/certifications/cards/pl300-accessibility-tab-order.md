## Behavior

In the Selection pane, set a useful tab order for report controls. Remove purely decorative shapes and images from that order.

## Defaults or baseline

The Tab order list permits reordering. Selecting the number next to an object removes it from tab navigation.

## Gotchas

A decoration need not remain a keyboard stop. Removing its tab stop differs from removing useful report controls.

## Verify

Read Tab order; Shapes; Images in the linked Microsoft source. No live Power BI model was tested.
