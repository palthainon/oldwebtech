## Behavior

For a button that opens a specific page in the same report, enable Action, choose Page navigation, and set Destination to that page.

## Defaults or baseline

Page navigation does not require a bookmark. Back returns to the previous report page instead of a fixed named destination.

## Gotchas

A button label alone does not configure its action. Use Destination to choose the page.
