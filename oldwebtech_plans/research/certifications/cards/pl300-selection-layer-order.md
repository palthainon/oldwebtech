## Behavior

Use the Selection pane to change the front-to-back order of overlapping visuals. Drag the visual name or use the arrow buttons.

## Defaults or baseline

Layer order determines which overlapping visual sits in front.

## Gotchas

Alignment controls position. It does not select the front-to-back order.
