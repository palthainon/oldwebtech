## Behavior

Enable Tooltip in Page Information to register a report page as a tooltip. Set the page size separately.

## Defaults or baseline

The Tooltip size template controls the canvas size. Page Information controls tooltip registration.

## Gotchas

A tooltip-sized page alone is not registered as a tooltip. Automatic field-based selection also needs compatible tooltip fields and summarization.

Read the exact Microsoft sections below. No live Power BI report was tested.
