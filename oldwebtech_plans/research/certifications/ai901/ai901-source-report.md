# AI-901 source research

Checked: 2026-10-12. Scope: sources for **original** Azure AI Fundamentals practice questions, not exam dumps or reproduced practice assessments.

## Current exam baseline

Microsoft's [AI-901 study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-901) says the English exam skills changed **April 15, 2026**; the page was last updated **July 13, 2026**. The current allocation is **Identify AI concepts and capabilities (40–45%)** and **Implement AI solutions by using Microsoft Foundry (55–60%)**. This is significantly more implementation focused than older AI Fundamentals outlines. Candidate prerequisites include basic Python, Azure resources, REST APIs, SDKs, and CLIs. The [exam page](https://learn.microsoft.com/en-us/credentials/certifications/exams/ai-901/) lists no retirement date as of this check.

Recommended question allocation for an initial 200-question bank: **85 concept questions / 115 Foundry implementation questions**, then tune to measured objectives and item performance.

## Question topic plan

1. **Responsible AI:** fairness, reliability/safety, privacy/security, inclusiveness, transparency, accountability. Use scenario questions that identify a specific design or monitoring choice.
2. **Model foundations:** what generative models do, capability selection, deployment options, configuration parameters, and tradeoffs.
3. **Workload selection:** text analysis, speech recognition/synthesis, computer vision, image generation, multimodal input, extraction, and agentic workflows.
4. **Foundry generative apps:** system and user prompts, model deployment, interactions in the portal, lightweight SDK clients, single agents, and agent clients.
5. **Foundry text and speech:** text analysis workflows, multimodal spoken prompts, Azure Speech in Foundry Tools.
6. **Foundry vision:** interpretation of visual prompts, generation of visual output, and lightweight vision applications.
7. **Content Understanding:** extracting structured data from documents/forms, images, audio, and video; choosing suitable analyzers and validating results.

Each item should carry the AI-901 objective ID, Microsoft source URL, source checked date, product version or feature status where relevant, original rationale, and an independent reviewer signoff. Avoid copying Microsoft practice assessment questions or textbook exercises.
