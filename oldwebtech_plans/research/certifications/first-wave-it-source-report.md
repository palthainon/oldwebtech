**Acquisition result:** nine new PDFs across these folders (three AWS exam guides, one ISC2 outline, two NIST standards, two open AI textbooks, one older Microsoft Press book). The initial sandboxed shell attempt failed DNS resolution. A direct publisher retry with approved network access succeeded for these nine files. The OpenIntro statistics PDF uses a $0 checkout rather than a direct PDF URL and was not downloaded; the Milne AI literacy PDF endpoint returned HTTP 403. Neither gap should block objective mapping.

**Behavior-card handoff:** start each card with the exam code and version, exact objective ID, source URL, checked date, claim, scope/conditions, exceptions, example scenario, and reviewer. Use vendor documentation for version-sensitive service behavior, the official outlines for exam mapping, and open/NIST sources for general concepts. Do not turn publisher sample questions, practice assessments, or textbook exercises into generated questions. Only approved cards should feed original item drafting.
