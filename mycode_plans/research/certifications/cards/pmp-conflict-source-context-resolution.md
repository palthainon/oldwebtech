# Behavior

- When a project disagreement arises, identify its source and analyze the context before implementing an agreed-on resolution strategy.
- Set and reinforce shared ground rules so the team and external stakeholders have a common basis for handling conflict.

# Gotchas

- Two specialists disagree about test order. Imposing a quick compromise before finding the source and context can leave the underlying conflict unresolved; first understand the disagreement, then work toward an agreed resolution.

# Verify

- In a scenario, check that the response identifies the conflict source, analyzes its context, and implements an agreed-on strategy, as described in People Task 2 of PMI's July 2026 outline.
