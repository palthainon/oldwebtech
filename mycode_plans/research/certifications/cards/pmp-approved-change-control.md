# Behavior

- Route proposed changes through the project change-control process, communicate their status, and implement changes after approval.
- Update project documentation to reflect an approved change.

# Gotchas

- Treating a request as authorization can cause unapproved scope or plan changes to enter delivery and leave project records inconsistent.

# Verify

- Trace a scenario from proposal through approval, implementation, and documentation against Business Environment Task 3 in PMI's current outline.

- PMP Business Environment, Task 3 (manage and control changes). No questions linked yet.
